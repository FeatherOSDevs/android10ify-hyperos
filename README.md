# android10ify-hyperos
A simple guide to make HyperOS look and feel like Android 10 — clean, minimal, nostalgic.

📱 HyperOS to Android 10 Style – Modding Guide
This project is a step-by-step guide to transform Xiaomi's HyperOS into a clean, minimal, and nostalgic Android 10 look.
Whether you're a fan of the old AOSP style or just want a lightweight and distraction-free experience, this repo provides the tools, apps, and tweaks to get you there.

🔧 What’s Included:
Launcher and icon pack suggestions (Pixel/AOSP style)

System UI adjustments (fonts, colors, control center tweaks)

Optional APKs and themes to enhance the Android 10 look

Screenshots and comparisons (before/after)

Extra resources to make it as close to Android 10 as possible

⚠️ Note: This guide does not require root, and focuses on safe, reversible modifications. Perfect for customization lovers who miss the classic Android vibe.

This is the result of the customization, very close to the original thing. 



First of all, you'll need:
-An HyperOS Device, Mi, Redmi, Poco...
-Lawnchair legacy
-"Pixel - Icon Pack" For general Icons
-Zedge (if you want sounds)
These themes:
"A13 Ultra" For boot animation
"Pixel experience" For system icons


First, download all the themes:
https://www.mtzfile.pw/detail/d5952bd8-7a22-4179-bfce-fdc135053ff4?srsltid=AfmBOopCIG-R4tZ_zknQxszorz8BlcMg7LAkmgv-w8gG7jYnGpIAypoF#gsc.tab=0
https://www.miuithemer.com/themes/pixel-experience-miui-theme-for-xiaomi-and-redmi-devices/


Now, go to the Themes app and apply like this:
"Pixel Experience" For icons
"A13 Ultra" For boot animatiom
*To change boot animation*
Go to themes app, user icon, click on "Customize Theme" and select "Boot Animation" to "A13 Ultra".

Now let's change the launcher
Go to the settings app and search on the top search bar:
"Default apps"
Click the "Default apps" option
Then on Launcher, select "Lawnchair"
<img src="https://github.com/user-attachments/assets/90c90870-2d06-49e8-81ec-cab57d2b6409" alt="screenshot" width="400"/>
And now you will have a brand new homescreen, but it still needs some settings.
Now, in lawnchair...
Long-press homescreen and select "Settings"
Now, navigate to "Theme"
If you didn't, download these icons:
https://play.google.com/store/apps/details?id=ru.pt.iconpack.pixel_q&hl=es_419
After that, go again to Themes and you will see "Icon Pack"
Choose "Pixel - Icon Pack"
<img src="https://github.com/user-attachments/assets/9409c0c4-622f-49f9-a9e4-992935014b76" alt="screenshot" width="400"/>
Also change icon shape to "Circle", idk why but by default its in square shape.
*Note that you can setup the "At a glance" Widget by pressing on it on the homescreen*
Ok, your setup it's pretty much finished.
